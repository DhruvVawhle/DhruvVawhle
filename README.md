## 🚀 Featured Projects

### 🛡️ [PromptShield](https://github.com/DhruvVawhle/PromptShield)
**Enterprise AI Security Gateway & Threat Intelligence Platform**

PromptShield is an AI security platform designed to inspect incoming prompts, detect potential threats, and enforce security policies before requests reach an LLM.

- **Threat Detection:** Identifies prompt injection, jailbreak attempts, system prompt extraction, and other adversarial inputs.
- **Security Policy Engine:** Applies risk scoring and deterministic actions such as `ALLOW`, `WARN`, `SANITIZE`, and `BLOCK`.
- **Hybrid AI Gateway:** Integrates Google Gemini and Groq with automatic provider failover.
- **Audit & Monitoring:** Provides security event tracking, incident management, and tamper-evident audit logs.
- **Security Dashboard:** Includes threat analytics, system health monitoring, and interactive security documentation.

<img src="https://skillicons.dev/icons?i=nextjs,ts,tailwind,firebase,redis" height="32" alt="PromptShield Tech Stack" />

[View Repository](https://github.com/DhruvVawhle/PromptShield)

### 🤖 [CampusAI](https://github.com/DhruvVawhle/Campus-AI)
**Autonomous Multilingual AI Campus Terminal & Reception Robot**

A multilingual AI-powered campus assistant developed for Shree L. R. Tiwari College of Engineering (SLRTCE), Mumbai.

- **Multilingual Voice Assistant:** Supports English, Hindi, Marathi, and Hinglish through speech recognition and text-to-speech.
- **Hybrid RAG System:** Uses FAISS-based document retrieval and structured SQLite data to answer campus-related queries.
- **Interactive Navigation:** Provides indoor wayfinding, SVG-based routes, and QR-based mobile handoff.
- **3D Robot Interface:** Features an animated avatar with interactive listening and speaking states.
- **Kiosk Experience:** Includes inactivity reset, microphone status monitoring, and technician diagnostics.
